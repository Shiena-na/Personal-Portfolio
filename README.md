# madebyshiena portfolio (GitHub Pages)

Folder structure:

    index.html
    css/style.css
    js/main.js           (skills list, contact form, animations; edit SKILLS here)
    assets/Shiena_Gawiran_Resume.pdf
    assets/images/       (hero, about and project images)

1. Upload everything in this folder to the root of your repo (e.g. `Shiena-na/Shiena-na.github.io`), keeping the folders.
2. Repo Settings > Pages > deploy from the `main` branch, `/ (root)`.
3. Contact form: after deploying, send one test message from the live site, then click the "Activate Form" link FormSubmit emails to gawiranshiena@gmail.com (one time only). Optional: set a Web3Forms key in `const W3F={key:''}` in `js/main.js`.
4. "Hire Me" / "Email" open Gmail compose.
5. Resume: replace `assets/Shiena_Gawiran_Resume.pdf` to update it (keep the filename). To swap a picture, replace the file in `assets/images/` with the same name.
