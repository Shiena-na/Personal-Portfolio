    Project Spotlight

    STI Library Management System

    Capstone project · Desktop application · C# · .NET Framework · SQL Server

    2nd Runner-Up, Poster Design & Brochure Design. Tap to enlarge.

    1Overview

    The STI Library Management System is a desktop-based application developed to help manage library operations at STI College Batangas. It was designed to support librarians in handling book records, borrowing and returning transactions, attendance monitoring, and inventory management through a centralized system.

    The project integrates barcode scanning to make book transactions and record retrieval more organized and efficient.

    2The problem

    Managing library records and daily transactions requires accurate recordkeeping and an organized way to monitor books and library activities. The project aimed to address the need for a more centralized approach to managing:

    • Book catalog and inventory records.
    • Borrowing and returning transactions.
    • Library attendance.
    • Lost, damaged, and overdue books.
    • Borrower records and transaction history.
    3Proposed solution

    We developed a standalone desktop application that brings essential library management tasks into one system.

    By integrating barcode scanning, the application allows librarians to process book borrowing and returns, identify library users through their ID barcodes, and maintain organized records of library activities.

    4Development process

    The system was developed using an Agile approach, allowing us to work through the different modules, test functionalities, and make improvements throughout development.

    1. Identifying library management requirements.
    2. Planning the database structure and application modules.
    3. Designing the user interface and system workflows.
    4. Developing and integrating the application with the database.
    5. Implementing barcode scanning functionality.
    6. Testing system features and documenting the results.
    5UI/UX design decisions

    The interface was designed with librarians and administrative users in mind. We focused on a straightforward layout, organized navigation, and accessible modules to make common library tasks easier to perform.

    The system includes a dashboard and dedicated sections for book cataloging, borrowing, returns, attendance, and other library records.

    6Main functionalities
    Login and DashboardAccess to the system and an overview of library activities.
    Book Catalog ManagementBook information, classifications, and barcode identification.
    Borrowing and ReturningRecords book transactions using barcode scanning.
    Attendance MonitoringTime-in and time-out through ID barcode scanning.
    Book Status TrackingOverdue, lost, and damaged book records.
    Transaction HistoryRecords of borrowing and returning activities.
    ID and Barcode GenerationGenerates barcode identifiers for library records.
    Backup and RestoreSupports database backup and restoration.

    The project gave me practical experience in C# desktop application development, SQL Server database management, barcode integration, and understanding how different system modules work together.
